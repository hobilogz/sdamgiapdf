## 🎯 Зачем создано это расширение?

При стандартной печати вариантов заданий с порталов «Решу ЕГЭ», «Решу ОГЭ», «Решу ВПР» на страницах остаются:
- Громоздкие шапки сайта и колонтитулы.
- Водяные знаки (*«решуегэ.рф»*, *«решуогэ.рф»*, *«решувпр.рф»*) поверх графиков и геометрических чертежей.
- Внутренние каталожные номера заданий (`№ 4  522269`), отвлекающие учеников.

**Sdamgia PDF Cleaner** решает все эти проблемы в один клик: вы получаете аккуратный, готовый к печати или отправке ученикам вариант в векторном PDF-качестве!

---

## ✨ Возможности

- 🚀 **Экспорт в 1 клик**: стильная плавающая кнопка **«Сохранить чистый PDF»** на любой странице варианта (включая режим печати `print=true`). Сама кнопка скрывается при печати и не попадает в документ.
- 🧹 **Очистка водяных знаков**: алгоритмически распознаёт и удаляет ватермарки со всех векторных SVG и растровых чертежей, не повреждая сами графики, оси, формулы и геометрические фигуры.
- 🔢 **Скрытие номеров каталога**: автоматически отключает чекбокс «№№ заданий» или скрывает номера каталога, оставляя только сквозную нумерацию задач (1, 2, 3...).
- 🧼 **Удаление мусора**: убирает шапку сайта, разделительные полосы, баннеры и служебные блоки портала.
- ⚙️ **Всплывающее меню настроек**: переключайте опции (скрывать номера, убирать ватермарку) в удобном popup-окне по клику на значок расширения.
- 🌐 **Полная совместимость со всеми проектами «Сдам ГИА»**:
  - `ЕГЭ`, `ОГЭ`, `ВПР`, `ГВЭ`, `ЦТ и ЦЭ`, `Олимп`, `Урок`, `СПО`, `ЕНТ` и другими разделами на доменах `*.sdamgia.ru`.

## 🚀 Установка расширения

Выберите ваш браузер и следуйте простой пошаговой инструкции:

### 🔹 Google Chrome, Яндекс.Браузер, Microsoft Edge, Opera, Brave

Расширение для данных браузеров находится в папке **[`extension-chromium/`](extension-chromium/)** или готовом архиве **[`dist/sdamgia-pdf-cleaner-chromium.zip`](dist/sdamgia-pdf-cleaner-chromium.zip)**.

#### Способ 1. Установка из распакованной папки (Рекомендуется)
1. Скачайте репозиторий: нажмите зелёную кнопку **`Code`** вверху страницы ➔ **`Download ZIP`** и распакуйте скачанный архив на компьютере.
2. Откройте страницу расширений в вашем браузере:
   - **Google Chrome**: скопируйте и вставьте в адресную строку `chrome://extensions`
   - **Яндекс.Браузер**: `browser://tune` (или `browser://extensions`)
   - **Microsoft Edge**: `edge://extensions`
   - **Opera**: `opera://extensions`
   - **Brave**: `brave://extensions`
3. В правом верхнем углу включите тумблер **«Режим разработчика»** (*Developer mode*).
4. Нажмите появившуюся кнопку **«Загрузить распакованное расширение»** (*Load unpacked*).
5. Выберите папку **`extension-chromium`** из распакованного репозитория.
6. Готово! Расширение активировано и готово к работе 🎉.

---

### 🦊 Mozilla Firefox

Расширение для Firefox адаптировано и находится в папке **[`extension-firefox/`](extension-firefox/)** или готовом архиве **[`dist/sdamgia-pdf-cleaner-firefox.zip`](dist/sdamgia-pdf-cleaner-firefox.zip)**.

1. Откройте в браузере Firefox адресную строку и введите:
   ```text
   about:debugging#/runtime/this-firefox
   ```
2. Нажмите кнопку **«Загрузить временное дополнение…»** (*Load Temporary Add-on…*).
3. Перейдите в папку **`extension-firefox`** и выберите файл **`manifest.json`** (либо выберите файл архива `dist/sdamgia-pdf-cleaner-firefox.zip`).
4. Готово! Расширение будет загружено в Firefox.

## 📖 Как пользоваться

1. Откройте любой составленный вариант на сайте СдамГИА (например, страницу версии для печати: `...&print=true`).
2. В правом верхнем углу страницы появится синяя кнопка **«Сохранить чистый PDF»**.
3. Нажмите на неё — расширение:
   - Моментально зачистит ватермарки с чертежей;
   - Скроет номера каталога и лишние элементы интерфейса;
   - Откроет штатное диалоговое окно печати браузера.
4. В поле «Принтер» (Назначение) выберите **«Сохранить как PDF»** и нажмите **«Сохранить»**.

> [!TIP]
> **Куда сохраняются файлы?**  
> При сохранении PDF браузер запоминает последнюю выбранную папку в Windows. Если вы один раз выберете нужную папку (например, *«Документы»* или *«Изображения»*), все последующие варианты будут предлагаться для сохранения сразу туда.

## ⚙️ Меню настроек

Кликните по иконке расширения на панели инструментов браузера, чтобы открыть быстрое меню:

| Опция | Описание | По умолчанию |
| :--- | :--- | :---: |
| **Выключать «№№ заданий»** | Автоматически скрывает каталожные идентификаторы заданий | `Включено` |
| **Убирать ватермарку** | Стирает надписи «решуегэ/огэ/впр» с чертежей и графиков | `Включено` |

Все настройки сохраняются мгновенно и синхронизируются в профиле браузера.

## 🔒 Безопасность и приватность

Данный проект создан с максимальным вниманием к безопасности пользователей:
- 🛡️ **100% Offline / Local**: расширение не содержит сторонних трекеров, телеметрии, аналитики и не отправляет никаких запросов во внешнюю сеть.
- 🔍 **Полностью открытый код**: исходный код не минифицирован и доступен для публичного аудита.
- 🔑 **Минимальные права**: запрашиваются только права `activeTab`, `scripting` и `storage`, ограниченные исключительно доменами `*.sdamgia.ru`.
- 🚫 В репозитории отсутствуют приватные ключи (`*.pem`), токены и персональные данные.
